# Java1.7Animations — حزمة أنيميشن جافا 1.7 لبيدروك

<div dir="rtl">

[English README](README.md)

هذه حزمة موارد (Resource Pack) تحاول نقل العديد من أنيميشن اللاعب من **Minecraft Java Edition v1.7** إلى **Minecraft Bedrock Edition** بأمانة ودقة. المساهمات مرحّب بها عبر طلبات السحب (Pull Requests)! وإذا وجدت خللاً، فضلاً افتح بلاغاً مفصّلاً في قسم Issues.

## العمل على الحزمة

المستودع هو الحزمة نفسها: المجلد الجذري هو ما يُضغط في ملف `.mcpack`، ومجلد `subpacks/` يحتوي الخيارات الفرعية (Subpacks) المدرجة في `manifest.json`. يوجد سكربتان بلغة بايثون بدون أي اعتماديات خارجية في مجلد [`tools/`](tools/README.md):

```bash
python3 tools/pack_check.py      # التحقق من JSON والمانيفست والـ subpacks والمراجع المتقاطعة
python3 tools/build_mcpack.py    # بناء artifacts/Java1.7Animations_v<version>.mcpack
```

شغّل المُحقِّق (validator) قبل فتح طلب سحب — فهو يمسك الأعطال المعتادة: تعليقات غير مغلقة، معرّف معلن مرتين في نفس الطبقة، مجلد subpack غير معلن في المانيفست، أو كنترولر يشغّل اسماً مستعاراً (alias) لا يعرّفه أي كيان (entity).

## التكامل المستمر والإصدارات (CI/CD)

- **CI** (`.github/workflows/ci.yml`): عند كل دفع (push) أو طلب سحب، يشغّل الاختبارات الذاتية للمُحقِّق، ثم يتحقق من الحزمة بوضع `--strict`، ثم يبني ملف `.mcpack` ويتأكد أن البناء قابل للتكرار (نفس البايتات)، ويرفع الملف كـ Artifact يمكن تنزيله من صفحة Actions.
- **الإصدارات** (`.github/workflows/release.yml`): عند دفع وسم (tag) يطابق نسخة المانيفست — مثل `v2.5.2` — يتم بناء الحزمة ونشر إصدار GitHub تلقائياً مع ملف `.mcpack` وبصمات SHA256 ومقتطف من سجل التغييرات:

```bash
git tag v2.5.2 && git push origin v2.5.2
```

إذا لم يطابق الوسم نسخة `manifest.json` يفشل النشر برسالة واضحة (يجب رفع النسخة في المانيفست أولاً).
